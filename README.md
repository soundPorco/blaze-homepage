# BLAZE BASKETBALL SCHOOL 公式HP

![](/images/readme-img1.png)

徳島県徳島市を拠点に活動するバスケットボールスクール 「BLAZE BASKETBALL SCHOOL」 の公式ホームページです。

スクールの概要、代表紹介、クラス案内、施設紹介、練習時間や諸費用の説明、レビュー、体験申込への導線を目的として制作しました。

## 開発背景

BLAZE BASKETBALL SCHOOLは、徳島のミニバスを長く指導してきた私の兄が2022年から運営を始めたバスケットボールスクールです。元々は主にInstagramを中心に情報発信を行っていましたが、

- 集客力のある情報発信が難しい
- スクールの理念や特徴が十分に伝わらない
- クラス情報が探しづらい
- 保護者が安心して申し込める情報が不足している
- 体験申込への導線が不明確

などの様々な課題がありました。

丁度その頃私が大学2年の頃、独学でHTML/CSS/JavaScriptを学習していた際に「実際にHPを制作・運営し、実務経験を積んでみたい」と考えたことをきっかけに、兄に相談を持ちかけてBLAZE BASKETBALL SCHOOLの公式サイトを制作することになりました。

HP制作を通じて、

- スクールの理念
- コーチ紹介
- 施設紹介
- クラスやコースの詳細な情報
- 練習時間・費用
- 生徒や保護者のレビュー・写真
- 体験申込までの動線案内

を分かりやすく伝えるためのサイト構成やデザインを考え、実装しました。

## 苦労した点

### 初めてのホームページ制作だったこと

本プロジェクトは、私にとって初めて制作したホームページでした。

当時は大学でWeb制作を学んでいたわけではなく、HTML・CSS・JavaScriptを独学で学び始めた段階だったため、何から手を付ければ良いのかも分からない状態からのスタートでした。

さらに、依頼者である兄はホームページ制作に強いこだわりがなく、

> 「かっこいい感じで、やりたいように作ってくれていいよ」

というスタンスでした。

自由度が高いことは一見良いことのように思えますが、実際には「何を作れば正解なのか分からない」という状態でもありました。

そこでまず、

- スクールの理念
- コーチ紹介
- クラス情報
- 練習時間・費用
- 施設紹介
- レビュー
- 体験申込導線

など、ホームページに掲載したい情報を洗い出し、ノートに整理するところから始めました。

また、スクール活動中の写真をどこで見せるか、どの順番で情報を伝えるかを考えながら、まずはセクションだけを並べた簡単な雛形を制作し、少しずつ形にしていきました。

今振り返ると、コードを書くよりも「何をどの順番で伝えるか」を考える時間の方が長かったように思います。

---

### 「作りたいもの」と「作れるもの」のギャップ

デザイン面でも大きな壁がありました。

制作当初は「ホームページ デザイン 参考」などで様々なサイトを調べていましたが、出てくるサイトはどれもレベルが高く、

- スクロールに合わせて動くアニメーション
- 独特な形に切り抜かれた画像
- 洗練されたスライダー
- 高度な演出

など、当時の自分では再現方法すら想像できないものばかりでした。

理想のデザインを見るたびに、

> 「かっこいいけど、これどうやって作るんだろう...」

と思っていました。

その結果、

「作りたいもの」と
「今の自分に作れるもの」

のギャップに悩みながら制作を進めることになりました。

最終的には無理に演出を詰め込むのではなく、

- 色数を絞る
- 余白をしっかり取る
- フォントを整える
- 写真を活かす

といったシンプルな方向へ舵を切りました。

制作の過程で本当に参考になったのは、デザインギャラリーサイトよりも、同規模のスポーツスクールのホームページや、当時アルバイトしていたラーメン屋のホームページでした。

「背伸びしすぎず、今できる範囲で良いものを作る」

という考え方を学んだ経験でした。

---

### レスポンシブ対応

このプロジェクトで最も苦労したのはレスポンシブ対応です。

ある程度PC版のデザインが完成した頃、

> 「そういえばスマホ対応を考えていなかった...」

ということに気付きました。

今なら考えられませんが、当時はとにかく形にすることに必死で、スマートフォンでどう見えるかをほとんど意識していませんでした。

実際にスマホ表示へ切り替えてみると、

- レイアウトが崩れる
- 画像が大きすぎる
- テキストが読みにくい
- スライダーが不自然

など問題だらけでした。

特にGridやFlexを利用して不規則なタイル状に配置していた画像やコンテンツの調整にはかなり苦戦しました。

この頃から、

> 「このデザインを採用したら、スマホではどう見せるか？」

を先に考えるようになりました。

ブラウザの開発者ツールやレスポンシブ確認用の拡張機能を使いながら何度も確認を繰り返し、レスポンシブデザインの重要性を身をもって学びました。

---

### ドメイン取得と公開

独自ドメインの取得と設定も大きな壁でした。

お名前.comでドメインを取得し、GitHub Pagesへ独自ドメインを設定するところまでは何とかできたものの、

- DNS
- Aレコード
- CNAME
- ネームサーバー

など聞き慣れない用語ばかりで、設定内容を理解するだけでも苦労しました。

さらに、一度は正常に表示されていたにも関わらず、後日Google検索経由でアクセスすると404エラーになる問題も発生しました。

GitHub Pages側の設定やDNS設定を何度も見直し、

> 「昨日まで動いていたのになぜ？」

と頭を抱えました。

最終的には、お名前.comから送られていたドメイン登録者確認メールへの対応が完了していなかったことが原因でした。

原因が分かった時は安心しましたが、

> 「じゃあ最初に表示できていたのはなぜなんだろう？」

という疑問は今でも完全には解決していません。

ただ、この経験によって、

「ホームページは作って終わりではなく、公開や運用まで含めて初めて完成する」

ということを強く実感しました。

---

### 公開後に発生したリンクの不具合

開発中はVS CodeのLive Serverを利用して動作確認を行っていました。

そのため問題なく動いていると思っていた内部リンクが、GitHub Pagesへ公開し独自ドメインを設定した途端に正しく動かなくなりました。

調査を進める中で、

「ローカル環境では動くが、本番環境では動かない」

というケースが存在することを知りました。

修正後はリンクの記述方法を見直しましたが、その影響で今度はローカル環境で確認するたびに公開中のサイトへ飛ばされるようになりました。

結果として、

1. コード修正
2. GitHubへPush
3. GitHub Pagesの反映待ち
4. ブラウザで確認

という流れを何度も繰り返すことになり、想像以上に時間がかかりました。

この経験を通じて、開発環境と本番環境の違いを意識することの重要性を学びました。

---

### 文章作成も担当することになった

サイトが完成に近づき、いよいよ文章を入れる段階になった時も困りました。

兄に

> 「どんな文章を載せたい？」

と聞いたところ、

> 「その辺も任せる」

との返答。

結局、兄が過去の取材で話していた内容やインタビュー記事などを参考にしながら私が文章を作成し、それを兄が修正するという形で進めました。

家族ならではの、かなりアバウトな制作体制だったと思います。

## 工夫した点

### 保護者目線を意識した情報設計

体験申込を検討している保護者が、

- どんなスクールなのか
- どんなコーチが指導するのか
- どんな環境で練習するのか

を短時間で把握できるように情報設計を行いました。

---

### モバイルファーストで設計

アクセスの大半がスマートフォンからであることを想定し、

- 読みやすい文字サイズ
- タップしやすい導線
- シンプルなナビゲーション

を意識して実装しました。

---

## 成果

- 実際にスクールの公式HPとして公開・運営をしている
- スクールの情報発信基盤として利用中
- 公開後もアクセス解析を行いながら保守・改善を続けている
- 月平均で表示回数約1100回、クリック数約170回、クリック率約15%を達成している。（2026年6月現在から直近3ヶ月）

## 今後の改善

### SEO改善

google search consoleやMicrosoft Clarityを導入し、検索順位やクリック率、検索ワードの確認、どこのセクションにユーザーが注目しているかなどを分析しながら、SEOの改善を進めていく予定です。現在ではHP冒頭のスクールの理念や代表の紹介などのセクションではなく、後半に位置しているクラスや施設紹介や、練習時間や費用のセクションにユーザーの注目が集まっていることが分かっているため、セクションの配置を変更して、ユーザーの関心に応じた情報提供を実現する予定です。
