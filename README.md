# BLAZE BASKETBALL SCHOOL 公式サイト

![トップ画像](画像URL)

スクール紹介、クラス案内、施設紹介、体験申込への導線を目的として制作しました。

## 開発背景

BLAZE BASKETBALL SCHOOLでは、主にSNSを中心に情報発信を行っていましたが、

- スクールの特徴が伝わりにくい
- クラス情報が探しづらい
- 保護者が安心して申し込める情報が不足している

という課題がありました。

そこで、

- スクールの理念
- コーチ紹介
- クラス情報
- 施設情報
- 体験申込

を分かりやすく伝えるための公式サイトを制作しました。

## 工夫した点

### 保護者目線を意識した情報設計

体験申込を検討している保護者が、

- どんなスクールなのか
- どんなコーチが指導するのか
- どんな環境で練習するのか

を短時間で把握できるように情報設計を行いました。

---

### モバイルファーストで設計

アクセスの大半がスマートフォンからであることを想定し、

- 読みやすい文字サイズ
- タップしやすい導線
- シンプルなナビゲーション

を意識して実装しました。

---

### 運用しやすい構成

スクール情報やレビューなどを更新しやすいように、セクションごとの責務を分離しながら実装しました。

---

## 苦労した点

実際のスクール運営者と相談しながら制作を進めたため、

「運営者が伝えたい情報」と
「保護者が知りたい情報」

のバランスを取ることに苦労しました。

掲載情報の優先順位を整理しながら構成を決定しました。
