ABOUT US

活動について

誰でも学べる
成長できる環境を

BLAZE BASKETBALL SCHOOL は、徳島県徳島市に拠点を置くバスケットボールスクールです。
「誰でも学べる、成長できる」環境を提供することをミッションに掲げ、U12（小学生）およびU15（中学生）を対象に、基礎から応用まで幅広いスキルを指導しています。
2022年の立ち上げ以来、延べ1,000人以上の子どもたちと向き合い、プロユースアカデミーへ進む選手も輩出しています。

試合で使える
「個のスキル」を学ぶ

BLAZE では、JBAの育成理論とNBAスキルコーチの「スキル構築」理論を融合させ、試合で本当に活かせる技術を習得します。
単なるドリルや形だけの練習ではなく、実戦の中で必要となる動き・判断・スキルを段階的に身につけられるカリキュラムです。

BLAZE BASKETBALL SCHOOL 代表

水上 陵

徳島中学校在学時には県大会優勝・ブロック大会出場を経験し、その後徳島商業高等学校を卒業。JBA公認C級ライセンスを取得し、21歳から現在まで14年間にわたり小中学生を中心に指導。中学強豪クラブチーム『VERTEX』のスキルコーチを務めるほか、徳島の優秀選手、並びに強豪クラブや徳島ガンバロウズユースの選手も通うスクールを運営。
2022年にBLAZE BASKETBALL SCHOOLを設立。以来、延べ1,000人以上を指導し、プロユースアカデミーへ進む選手も輩出。

CLASS INTRODUCTION

成長を加速させる、クラスラインナップ

クラスは、目的やスキルに応じて段階的に設計されており 、初めてバスケットボールに触れるお子様も、ステップアップを目指す経験者も、ここでなら着実な成長を実感できるはずです。

受講者の経験、目的に応じて複数のコースをご用意しています。 初心者から上級者まで、安心して学べる充実したカリキュラムで、確かな成長をサポートします。 それぞれのニーズに合った最適なコースをぜひご覧ください。

ベーシッククラス

BASIC CLASS

バスケの基礎を楽しく学ぶ入門クラス

身体の使い方、ボールハンドリング、正しいシュートフォームなど、 バスケットボールの基本技術を楽しく学べる入門クラスです。
ファンダメンタル（基礎）の習得を通じて、スキルの土台をしっかり築いていきます。

こんな人におすすめ

  • ● バスケ初心者（U12〜U15）
  • ● 基礎から丁寧に学びたい方
  • ● チーム練習だけでは補えないスキルを身につけたい方

クラス概要

日程： ※詳しくは練習時間についてをご覧ください
対象： 小学生〜中学生（バスケットボールの基礎を身につけたい男女）
コース： 週1回・週2回コースから選択可能
特典： 新規入会でオリジナルTシャツプレゼント
料金： 月額6,000円〜11,500円（税込） ※詳しくは月会費・諸費用についてをご覧ください

バスケットボールの楽しさは、確かな基礎から始まります！

このBASIC CLASSは、バスケットボールを始めたばかりのお子様や、もう一度基礎からしっかりと学び直したいお子様に最適なクラスです。 スキルの土台となるファンダメンタル、つまり「身体操作」「ボールの扱い」「シュート」といったバスケットボールの根幹を、時間をかけて丁寧に構築していきます 。
一人ひとりのレベルに合わせて指導を行うことで、正しいフォームと動きを習得し、バスケットボールの楽しさを深く実感できるでしょう。このクラスで身につけた確かな基礎は、お子様のバスケットボール人生を豊かにするかけがえのない財産となります。

アドバンシッドクラス

ADVANCED CLASS

実戦的スキルを鍛える競技特化型クラス

実戦を想定した状況判断やプレー選択を含めた、より高度なスキルの習得を目指すクラスです。
実践的なトレーニングを通じて、競技力の向上に特化した内容を提供します。

こんな人におすすめ

  • ● U15 または U12 の上級者
  • ● 実戦で通用する判断力と応用スキルを高めたい選手
  • ● より競技性の高い環境でステップアップしたい方

クラス概要

日程： ※詳しくは練習時間についてをご覧ください
対象： 小学生高学年〜中学生（競技力向上を目指す男女）
特典： 新規入会でオリジナルTシャツプレゼント
コース： 週1回・週2回コースから選択可能
オプション： WEEKEND FREE 追加可能
料金： 月額6,000円〜11,500円（税込） ※詳しくは月会費・諸費用についてをご覧ください

次のレベルへ！実践で活きるスキルを習得し、試合で輝こう！

ADVANCED CLASSは、バスケットボールの経験があり、さらに競技力を向上させたいと願うお子様のための、より実践的で競技に特化したクラスです 。
このクラスでは、単なる技術の習得に留まらず、「判断を伴う実戦的なスキル」の養成に力を入れています 。試合中に刻々と変化する状況を正確に判断し、適切なプレーを選択する能力、そしてそれを実行する高度なスキルを磨きます。より複雑な戦術やチームプレーにも挑戦し、個々の能力をチームの中で最大限に発揮できるよう指導します。
将来、大会での活躍を目指すお子様にとって、このクラスはまさに飛躍の場となるでしょう。

バスケットボールを通じて、運動の楽しさを体感しよう！

KIDS CLASSは、幼児から小学校低学年のお子様を対象に、運動能力の基礎を楽しく育むクラスです。

このクラスでは、運動を通じて協調性や自信を育むことを目指し、子どもたちが笑顔で成長できる環境を提供します。

シューティングクラス

SHOOTING CLASS

【2026年3月新規開設】シュート力向上特化型クラス

こんな選手におすすめ

  • ● 正しいシュートフォームを基礎から学びたい
  • ● もっとシュートを打ち込める環境が欲しい
  • ● 何をどう練習すれば良いかわからない

クラス概要

日程：木曜 18:15〜19:45 ／ 金曜 20:00〜21:30

このクラスで得られる成果

シュートは「才能」ではなく「再現性」。
